# Saiborg Discord Integration
## What is this?
This is a **discord bot** designed to aid in the efficiency of managing different servers. 
Saiborg connects to the iOS app, Saiborg, which is the dashboard for discord and slack server communication.

## How does it work?
- cd into the directory in which this project exists.
- Create a virtual environment to isolate dependencies for the project and avoid conflicts between projects, using the following commands.
  - '''python3 -m venv .venv'''
  - '''source .venv/bin/activate'''
- Run the bot using the following command:
  - '''python bot.py'''

## Why is it useful?
Do you have many clubs to run? Or university course servers to keep a track of? 
Saiborg identifies and summarizes all the important texts you need to respond to!
